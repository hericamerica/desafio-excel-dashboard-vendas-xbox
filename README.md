# 🎮 Xbox Game Pass Subscriptions Sales - Dashboard em Excel

Projeto desenvolvido como desafio prático para a **DIO (Digital Innovation One)**. A solução consiste em um **Dashboard Executivo de Vendas** construído no Excel para analisar o desempenho comercial das assinaturas do **Xbox Game Pass**, integrando dados de planos, renovações automáticas e pacotes adicionais (*Season Passes*).

---

## 🎯 Objetivo do Projeto

Transformar dados brutos de inscritos em uma ferramenta visual e estratégica para tomada de decisões. O painel responde a perguntas de negócio essenciais relacionadas a faturamento total, retenção por renovação automática e adesão a complementos como *EA Play* e *Minecraft Season Pass*.

---

## 🛠️ Estrutura e Organização da Planilha

A solução foi estruturada de forma modular e profissional dividida em 4 abas:

- **🖥️ Dashboard:** Painel principal com visão executiva (*Xbox Game Pass Subscriptions Sales*), apresentando os KPIs de vendas, filtros e gráficos dinâmicos para análise do gestor.
- **🧮 Cálculos:** Aba técnica de consolidação dos dados onde são processadas as perguntas de negócio (Faturamento total de planos anuais, distribuição por auto-renovação, total acumulado de assinaturas EA Play e Minecraft).
- **📊 Bases:** Base de dados relacional com registros de assinantes (Subscriber ID, Nome, Plano: *Ultimate/Standard/Core*, Tipo: *Monthly/Quarterly/Annual*, Renovação Automática, Preços e Cupons).
- **🎨 Assets:** Manual de identidade visual do projeto, contendo a paleta de cores padronizada da marca Xbox (ex: `#22C55E`, `#9BC848`), menus e ícones.

---

## ⭐ Diferenciais e Recursos do Dashboard

- **Resolução de Perguntas de Negócio:** Mapeamento claro do faturamento por tipo de assinatura e impacto da renovação automática na receita.
- **Análise de Adicionais (Add-ons):** Acompanhamento de adesão aos passes de temporada do *EA Play* e *Minecraft*.
- **Design Executivo e UI/UX:** Layout moderno com tema escuro e verde Xbox, simulando um painel do sistema/console.
- **Separação de Camadas (Model/View):** Separação clara entre a base de dados bruta, a camada de cálculos dinâmicos e a interface visual do usuário.

## 🚀 Como Visualizar e Utilizar

1. Faça o download do arquivo `Dashboard de Vendas do Xbox.xlsx` disponível neste repositório.
2. Abra o arquivo no **Microsoft Excel** (versão desktop recomendada para melhor renderização dos elementos visuais e segmentadores).
3. Navegue até a aba **Dashboard** para analisar os indicadores de vendas e simular cenários.
